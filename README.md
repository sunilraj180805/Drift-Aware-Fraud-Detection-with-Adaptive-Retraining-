# Drift-Aware-Fraud-Detection-with-Adaptive-Retraining-
Drift-aware fraud detection on the Elliptic Bitcoin dataset — unsupervised drift signals (PSI, MMD) trigger selective model retraining, lifting post-drift F1 from 0.009 to 0.390 (p &lt; 0.0001, n=10 seeds) across XGBoost, GraphSAGE, and TGAT architectures.
